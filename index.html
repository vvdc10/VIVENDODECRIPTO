1) Informações que você precisa para integrar a API

  • Credenciais da corretora: API Key, API Secret e ambiente (sandbox/produção).
  • Endpoints: preço ao vivo, saldo, envio de ordem, histórico de ordens.
  • Regras de risco: risco por trade, drawdown diário, stop/take.
  • Dados de mercado: par (ETH/USDT), timeframe (M1), indicadores exigidos.
  • Segurança local: não compartilhe credenciais e use apenas ambiente de teste.

2) Fluxo com backend local

Fluxo recomendado:

Tela NEXUS → Backend local (/signal) → resposta da IA → decisão manual do operador

A IA sugere sinal e níveis via backend. A execução da ordem segue manual.

3) Prompt-base melhorado para sua IA

Você é um analista quantitativo de ETH/USDT no timeframe M1. Use EMA(9,21,50,200), RSI(14), MACD(12,26,9), VWAP e Bollinger. Responda em JSON válido: { "signal": "LONG|SHORT|NEUTRAL", "confidence": 0-100, "entry": number, "stop_loss": number, "take_profit_1": number, "take_profit_2": number, "risk_reward": number, "reasons": ["..."], "invalid_if": ["..."] } Nunca invente preço. Se confiança < 70, retorne NEUTRAL.
